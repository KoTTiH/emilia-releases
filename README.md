# Эмилия — выпуски

Здесь только готовые сборки программы «Эмилия»: маскот рабочего стола, который танцует в бит музыки.
Сайт: https://emilia-moth.ru

Скачивайте только отсюда (вкладка **Releases**) или по кнопке на сайте. Копии в других местах могут быть подделкой.

## Установка

**Windows 10/11.** Скачайте `Emilia-Setup-<версия>.exe` и запустите. Программа пока без цифровой подписи,
поэтому Windows покажет «Система Windows защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**.

**Linux (Hyprland, Sway, KDE, niri).** Скачайте `Emilia-<версия>-x86_64.AppImage`, сделайте его исполняемым
(`chmod +x Emilia-*.AppImage`) и запустите.

## Проверка файла

К каждому выпуску приложен `SHA256SUMS`. Сравните сумму скачанного файла:

- Linux: `sha256sum -c SHA256SUMS --ignore-missing`
- Windows (PowerShell): `Get-FileHash .\Emilia-Setup-<версия>.exe -Algorithm SHA256`

Суммы должны совпасть с теми, что в `SHA256SUMS` и на сайте.
